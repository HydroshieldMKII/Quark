# Security policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting (Security tab, *Report a vulnerability*). Include the
Quark and CLI versions (`quark --version`, `proton-drive --version`), the steps, and the expected
behaviour. Logs are redacted; check them for personal data before attaching.

## Supported versions

The latest release and `main`.

## Out of scope

Vulnerabilities in the Proton Drive CLI or in Proton's services; report them to Proton.
